# EVE-NG VM

## Download EVE-NG

- "Downloads" Tab

- EVE-NG Community

- EVE-NG OVA - Google Mirror

## Download Hypervisor - "VMware Workstation Player"

- From EVE-NG Website

- After installation, open "Workstation Player"

- Player > File > Open

- Select "EVE Community VM" in the "Downloads" folder

## Edit VM Settings

- RAM: 4 GB

- Network Adapter: NAT for Laptop, Bridged for Desktop

## Power on the VM

- Set up a password for Root

- Do other initial config, then reboot the VM

- After reboot, ping google.com to make sure the VM has internet

- Access the VM by typing its address on the browser, using "admin" as the username

- Add a new lab


# Lab Features

- Inter-VLAN Routing

- LACP EtherChannel

- RPVST+ & VRRP Sync

- OSPF (multi-area)

- SNMP monitoring & Syslog collection

- Ansible Network Automation
