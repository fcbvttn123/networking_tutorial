# NOC

## Overview

In the networking industry, NOC stands for Network Operations Center. It refers to a centralized location—or the team operating within it—responsible for continuously monitoring, managing, and maintaining telecommunications networks, data centers, and enterprise IT infrastructures.

The primary mission of a NOC is to ensure maximum network availability, performance reliability, and rapid incident response.

## Core Responsibilities

**Continuous Monitoring:** Overseeing network telemetry, link statuses, bandwidth utilization, latency, and device health across switches, routers, firewalls, and servers using centralized monitoring platforms (such as Zabbix, Prometheus, or SNMP-based tools).

**Incident Detection and Triage:** Receiving automated alerts, acknowledging alarms, performing initial diagnostics (e.g., ping tests, traceroutes, interface error checks), and determining the severity and scope of an outage.

**Incident Escalation:** Resolving first-line issues using standard operating procedures (SOPs) or escalating complex, high-priority issues to Tier 2/Tier 3 engineering teams or external telecommunications vendors.

**Change Management:** Executing or overseeing scheduled network maintenance, firmware upgrades, and configuration changes during designated maintenance windows to minimize business disruption.

**Security & Traffic Anomalies:** Identifying unusual traffic patterns, potential DDoS attacks, interface saturation, or unauthorized network access attempts in coordination with Security Operations Centers (SOCs).

## Typical NOC Tier Structure

Tier 1 (NOC Analysts / Operators): The frontline team monitoring dashboard screens, acknowledging initial alerts, logging trouble tickets, performing basic triage, and executing predefined remediation scripts.

Tier 2 (Engineers): More experienced systems and network engineers who handle complex routing/switching problems, deep packet analysis, advanced hardware troubleshooting, and configuration reviews.

Tier 3 (Subject Matter Experts / Architects): Senior engineers or architects who handle severe critical outages, root-cause analysis (RCA), vendor-level escalations, and infrastructure redesigns.
